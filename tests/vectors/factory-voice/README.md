# Factory voice fixtures

These fixtures contain synthetic speech and silence. They are available under
the repository's [Apache License 2.0](../../../LICENSE).

| WAV | Spoken text or control |
| --- | --- |
| `retry-label.wav` | “Change the button label to Retry” |
| `preserve-timeout.wav` | “Keep the existing timeout. Do not change it” |
| `preserve-timeout-padded.wav` | The same text with two seconds of silence at each end |
| `silence.wav` | Three seconds of digital silence |
| `issue-number.wav` | “Change issue forty two” in a different synthetic voice |

The WAVs are mono 16-bit PCM at 22,050 Hz. The two unpadded commands also have
MP3, MP4/AAC (`.m4a`), and WebM/Opus copies for decoder tests.

Run `curie dev regenerate-voice-fixtures` from a source checkout with uv and
Python 3.13. Use `curie dev regenerate-voice-fixtures --check` to compare the
generated bytes with the committed files. The command uses the pinned
`espeakng-loader` 0.2.4 and PyAV 19.0.2 wheels. Byte comparison uses the same
platform wheel builds. CI reads the committed files.

Speech was generated with [eSpeak NG](https://github.com/espeak-ng/espeak-ng),
which is licensed under GPL-3.0-or-later. The fixtures contain its generated
audio. The eSpeak NG program and voice data are distributed by the loader
wheel.
